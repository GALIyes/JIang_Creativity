# JIang_Creativity
This repository collects my personal technical practice projects.
It covers embedded developments based on **STM32, CPLD and FPGA**, hardware PCB designs completed with JLC‑EDA and Altium Designer, simple frontend demos built by HTML, CSS and JavaScript, as well as homemade lightweight AI tools.
All contents are shared for learning and reference, focusing on embedded‑related hardware exploration and hands‑on experiments.
